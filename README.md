# Avito Plus — поиск объявлений на своём компьютере

**Первый релиз: Windows + LM Studio + запуск одной кнопкой.** Это локальное приложение с интерфейсом в браузере. Облако, домен, HTTPS, Docker и аккаунты для него не нужны.

## Что делать другу сейчас

Передайте Claude Opus 4.6 [готовый промпт реализации](docs/CLAUDE_LOCAL_MVP_PROMPT.md). Он задаёт небольшой законченный scope, без обязательного прохождения прежнего серверного плана.

До merge PR #1 откройте ветку `codex/repository-plan-20261015`. В ней опубликованы документы и канбан; исходный Python/JS/HTML пока есть только в переданной локальной папке. Если Claude подключён лишь к GitHub, дайте ему исходники через отдельную чистую копию/архив: пять Python modules, templates/index.html и static/app.js. Не отправляйте browser profiles, cookies, историю, debug captures и .env. Без исходников нельзя реализовать приложение по одному описанию.

## Как будет выглядеть использование после реализации

1. Один раз запустить `Установить.cmd` — подготовит зависимости и нужный browser binary.
2. Открыть LM Studio, загрузить подходящую модель и включить local API server.
3. Дважды нажать `Запустить.cmd` — откроется Avito Plus в браузере.
4. Искать товары, листать результаты, смотреть фото и объяснение выгодности.
5. Нажать `Остановить.cmd` либо использовать понятное завершение в окне запуска.

**Эти .cmd файлы ещё не созданы: это цель AP-016/AP-017, а не инструкция запустить существующий релиз.** Закрытие вкладки само по себе не обязано останавливать Python. LM Studio остаётся под управлением пользователя; приложение не должно завершать его процесс.

Если LM Studio недоступна — интерфейс объясняет, что включить, и позволяет искать без AI. Сам поиск требует интернет-доступа к источнику; «локальный» не означает offline-поиск. При 403/429/CAPTCHA показывается недоступность, а не выдуманные товары.

## Что важно сохранить даже в простой версии

- Цена, название и ссылка относятся к одному реальному объявлению.
- Несколько страниц содержат новые реальные результаты, не повтор тех же семи карточек.
- Фото относится к товару; если недоступно — placeholder.
- Оценка «выгодно» объяснима и относится к собранной сравнимой выборке, не гарантирует прибыль или лучшее предложение всего рынка.
- Личные browser profiles/cookies/history не попадают в public Git.
