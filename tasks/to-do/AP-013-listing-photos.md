# AP-013 — фотографии объявлений

Priority: P1. Owner: UNASSIGNED. Blocked: согласованный источник AP-006.

## Запрос пользователя
Показывать фотографии товара из исходного объявления в результатах сервиса.

## Scope
Проверить, какие изображения доступны выбранным допустимым способом получения объявления. ListingItem уже имеет image_url, scraper пытается извлечь img src, но текущая карточка UI фото не отображает. Не считать эту попытку доказательством работающего извлечения.

Первый вариант — thumbnail по проверенному HTTPS URL с placeholder при отсутствии/ошибке, lazy loading и корректным alt. Не создавать image proxy/download endpoint с произвольным URL. Если hotlink недоступен/не допускается источником, показать placeholder и исходную ссылку; не обходить ограничения. Хранение/caching изображений и права использования выбрать отдельно.

## Зависимости
AP-004, AP-006, AP-008. Metadata фото принадлежит тому же listing ID, что title/price/link. AP-014 задаёт правила идентичности.

## Приёмка
- Фото соответствует объявлению; нет общей картинки, выданной за фото товара.
- Missing/blocked/broken URL не ломает выдачу; placeholder явно нейтрален.
- URL scheme/host проверены, HTML не исполняется, image load ограничен; учтено раскрытие IP/referrer при direct load.
- Mobile/desktop и lazy loading проверены по отдельному поручению; источник/retention описаны.

## Результат
NOT_STARTED. Доступ к реальным фото/условия использования не проверены. Код/live requests NOT_RUN.
