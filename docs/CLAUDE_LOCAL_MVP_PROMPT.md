# Промпт для Claude — простой локальный Avito Plus

Скопируйте сообщение ниже в Claude Opus 4.6 с доступом к исходникам. До merge PR #1 документы находятся в ветке `codex/repository-plan-20261015`.

---

Сделай Avito Plus удобным локальным приложением для Windows. Я хочу открыть LM Studio, загрузить модель, включить local API server, нажать «Запустить» и пользоваться поиском в браузере. Без облака и сложной настройки.

Прочитай AGENTS.md, docs/LOCAL_MVP.md и задачи AP-016/AP-017. Проверь реальные исходники: app.py, models.py, scraper.py, analyzer.py, market.py, templates/index.html и static/app.js. Если в доступном repo только документация, один раз попроси эти файлы или путь к ним; browser profiles, cookies и .env не нужны. Не создавай приложение заново по описанию.

Доведи до реализации два этапа:

1. **Удобный запуск.** Один `Установить.cmd` для project venv/зависимостей и `Запустить.cmd`/`Остановить.cmd`. Start открывает браузер после готовности сервера, работает с пробелами/кириллицей в пути, не плодит процессы. Stop завершает только свои процессы, не LM Studio. Приложение доступно только на 127.0.0.1.
2. **Полезный поиск.** Реальные объявления с согласованными ценой/названием/ссылкой, несколько страниц с dedup, фото с placeholder, рабочие фильтры и простое объяснимое ранжирование сравнимых предложений. Сначала исправь достоверность, затем количество и рекомендации. Не подставляй выдуманные товары при ошибке; «лучшие» означает среди найденных, не всего рынка.

Подключи уже работающую LM Studio через настройки localhost URL/model; по умолчанию `http://127.0.0.1:1234/v1`. Покажи понятный выбор модели. Если API выключен — объясни, что включить, и разреши поиск без AI. Никаких внешних платных API или автоматической загрузки моделей.

Сохрани текущие root modules и HTML/JS, не делай обязательный перенос в src, SPA, Docker, аккаунты или серверную инфраструктуру. Принимай обычные решения самостоятельно. Спрашивай только при настоящем блокере; не останавливайся на очередном плане.

Разрешаю локальные offline/mocked проверки сделанных изменений. Исходные live test_*.py не запускать автоматически. Реальные Avito/browser/LM Studio запросы и установки выполняй только по отдельному разрешению; иначе дай короткий ручной checklist и отметь NOT_RUN. При 403/429/CAPTCHA — честная недоступность, без обхода. Не копируй личные cookie базы, не публикуй private данные. Сохрани безопасный DOM/URL, небольшой лимит запросов и cleanup, без enterprise security проекта. Git push/merge и новые расходы отдельно не разрешаю.

В конце обнови задачи по реальному результату и дай коротко: что готово, что проверено, что осталось и какие кнопки мне нажать. Цель — готовые файлы и минимум действий с моей стороны.
