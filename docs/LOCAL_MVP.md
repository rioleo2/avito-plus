# Локальный MVP — текущая цель

Решение пользователя 15.10.2026: другу нужен инструмент на своём компьютере — открыть LM Studio, запустить приложение и пользоваться браузерным интерфейсом. Это заменяет cloud-first план как ближайший scope.

## Два законченных этапа

**AP-016: удобный запуск.** Сохранить root app.py/models.py/scraper.py/analyzer.py/market.py и templates/static. Не переносить в src и не делать SPA. Подготовить один setup, start и stop для Windows; зависимости фиксируются минимально достаточным способом. Setup ставит только в project venv, не требует admin и не меняет глобальный ExecutionPolicy/PATH. Проверяет Python; если его нет — даёт одну короткую инструкцию, не автоматизирует всё окружение компьютера.

Start использует абсолютный project path, работает из папки с пробелами/кириллицей, запускает local server на 127.0.0.1, ждёт ограниченное время health, затем открывает браузер. Повторный запуск не создаёт дубликат. Занятый чужим приложением порт — понятное сообщение, не kill чужого процесса. Stop останавливает только принадлежащие приложению server/browser children, не LM Studio/все python.exe. Простое видимое окно статуса предпочтительно сложно устроенному скрытому daemon/tray.

LM Studio: пользователь сам открывает приложение, загружает модель и включает server в Developer. Endpoint по умолчанию http://127.0.0.1:1234/v1; порт/модель/необязательный локальный token настраиваются без редактирования Python. Проверка доступности/model list имеет timeout; выбрать единственную обнаруженную модель либо понятный список, не полагаться на literal local-model. Нет внешнего fallback API/платного inference/автоматической загрузки большой модели. Ошибка AI не блокирует поиск и не выдаётся за успешный AI result.

**AP-017: полезная выдача.** Исправить silent curated/generated fallback; сохранить 0/1/2 live результата. Проверять listing identity/price/link. Добавить bounded multi-page collection, dedup и UI «Ещё»/страницы без выдуманного total; фото с безопасным URL/placeholder. Затем простое объяснимое ranking по сравнимым товарам/цене/рискам. Если данных мало, честно сообщить. Не нужно выполнять все прежние карточки как отдельные approval циклы.

## Минимальные границы

Bind только loopback. Не нужны multiuser auth, HTTPS/domain, VM, Redis/DB/queue service. Нужны небольшой общий лимит поиска, bounded ожидание/timeout/cleanup, безопасные DOM text/URLs и защита local API от произвольных cross-origin calls. Не отключать браузерные protections ради удобства.

Source adapter не должен автоматически копировать личную cookie SQLite. Если выбранному доступному сценарию нужна сессия, использовать отдельный app context и понятное добровольное действие пользователя; profiles не импортировать в Git. При блокировке источника остановка/сообщение, не stealth/captcha bypass.

## Приёмка

Друг знает только три действия: включить LM Studio API → запустить ярлык → пользоваться. Один раз требуется setup. Предусмотрены: LM Studio выключена/модель не выбрана, занятый порт, повторный start/stop, путь с пробелами, ошибка источника. Offline/mocked checks по поручению не должны запускать корневые live test_*.py. Windows/LM Studio/live source проверки фиксируются отдельно; здесь всё NOT_RUN.

## Официальная справка, прочитана 15.10.2026

LM Studio описывает старт local API server через Developer → Start server: https://lmstudio.ai/docs/developer/core/server . Bind 127.0.0.1 оставляет server локальным: https://lmstudio.ai/docs/cli/serve/server-start . Фактические версия/model/настройки компьютера друга не проверены. Открытого окна LM Studio недостаточно, если API server ещё не включён.
