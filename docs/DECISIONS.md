# Текущие решения

- 15.10.2026 пользователь уточнил цель: друг хочет инструмент на своём Windows PC с уже установленной LM Studio, минимум настройки.
- Приоритет — root FastAPI/HTML приложение, setup/start/stop в один клик, local loopback; не Cloud.ru.
- Самостоятельный проект rioleo2/avito-plus. Публикация обновлённого плана и промпта разрешена; код сейчас не реализуется.
- Сначала AP-016, затем AP-017. Облачные AP-010/011/012 и package AP-003 отложены; прежний public-first roadmap не текущий gate.
- Достоверность real listings, несколько страниц/фото/ранжирование сохраняются. Fake fallback и unsafe HTML нельзя оставлять ради простоты.
- Конкретная модель/версия LM Studio, установленный Python и доступный source scenario не проверены. Уточнять лишь при реальном blocker. Необязательные продуктовые решения не превращать в анкету.

Код/установка/runtime/tests NOT_RUN. Авторские source файлы пока локально, в GitHub только docs/scaffold. Права на code publication/allowlist проверяются при AP-001; использование своих локальных файлов не требует ждать публикации кода или выбора open-source лицензии.
