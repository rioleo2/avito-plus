# Avito Market AI Analyzer

Локальный инструмент: ищет объявления на Авито, считает рыночную вилку цен и показывает **самые выгодные предложения**.
Оценку лотов делает нейросеть в LM Studio (локально, без облака).

## Требования

- Windows 10/11, Python 3.10+ (в PATH).
- [LM Studio](https://lmstudio.ai) со скачанной чат-моделью (проверялось на `qwen2.5-7b-instruct`).
- Браузер Zen с залогиненным Авито — из него берутся куки (см. «Приватность»). Без кук всё работает, но Авито чаще показывает капчу.

## Как запустить

Дважды кликните **`start.bat`** (краткая версия — в [ЗАПУСК.md](ЗАПУСК.md)). Он сам:

1. доустановит Python-пакеты и Firefox для Playwright (только при первом запуске);
2. запустит LM Studio и дождётся его сервера (`http://localhost:1234/v1`);
3. запустит сайт на `http://127.0.0.1:8000`;
4. откроет его в браузере.

Остановить: закройте окно консоли или нажмите `Ctrl+C`.

### Если LM Studio не стартует сам
- Путь к программе берётся из файла `lmstudio_path.txt` (одна строка — путь к `.exe`). Файл не коммитится.
- В LM Studio должна быть скачана модель, а сервер включён: **Developer → Start Server**.
  Чтобы это происходило само, включите в настройках LM Studio «Enable Local LLM Service».
- Без LM Studio сайт работает, но оценка идёт только по правилам (без ИИ).

## Как это работает

1. **Выдача**: Playwright (Firefox) открывает несколько страниц поиска Авито (по умолчанию 3 ≈ 150 объявлений),
   берёт название, цену, описание, дату и **фото** (до 5 кадров слайдера).
   Куки берутся из вашего профиля Zen — так Авито видит обычного пользователя.
2. **Рынок**: аксессуары, запчасти, «куплю», аренда отсеиваются; медиана и квартили считаются без выбросов.
3. **Сверка цен**: лучшие кандидаты открываются на странице самого объявления. Если цена там другая —
   берётся реальная, лот помечается «цена изменилась»; снятые с публикации исключаются.
4. **ИИ**: топ-6 лотов разбирает LM Studio (состояние, дефекты, красные флаги).
5. **Рейтинг**: балл = скидка к медиане − штрафы за риски ± поправка ИИ. Подозрительно дешёвое (< 40% рынка) в «лучшие» не попадает.

## Удобства в интерфейсе

- **Город** — любое название, можно писать самому («Тверь», «Ростов-на-Дону»). Популярные подставляются подсказкой;
  остальные переводятся в адрес Авито автоматически. Если Авито такого города не знает, сайт так и скажет.
- Заголовок «Анализ Авито» — ссылка на главную. Кнопка **Отменить** прерывает долгий анализ.
- Настройки (город, страницы, цены…) и последние 8 удачных запросов запоминаются в браузере.
- Свежая выдача (до 20 минут) берётся из кэша, чтобы не нагружать Авито; галка «Не брать из кэша» обновляет принудительно.

## Если Авито ответил «Доступ ограничен» (403/429)

Это защита от частых запросов. Подождите 15–30 минут. Повторные запросы с теми же параметрами 20 минут берутся из кэша
(`.cache/`) и Авито не нагружают. Между страницами сайт сам делает паузы — не уменьшайте их в `config.py`.

## Настройки (`config.py`, можно переопределять переменными окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `LM_BASE_URL` | `http://127.0.0.1:1234/v1` | адрес сервера LM Studio |
| `LM_MODEL` | первая не-embedding модель | какую модель использовать |
| `LMSTUDIO_EXE` | — | путь к LM Studio, если не указан в `lmstudio_path.txt` |
| `ZEN_PROFILES_DIR` | `%APPDATA%\zen\Profiles` | где искать куки Авито |
| `APP_PORT` | `8000` | порт сайта |
| `CACHE_TTL_SECONDS` | `1200` | сколько хранить выдачу |

## Структура проекта

| Файл | За что отвечает |
|---|---|
| `start.bat`, `launcher.py` | запуск одним кликом: зависимости → LM Studio → сайт → браузер |
| `app.py` | веб-сервер FastAPI; анализ идёт фоновой задачей, интерфейс опрашивает прогресс |
| `pipeline.py` | весь цикл: выдача → рынок → сверка цен → ИИ → рейтинг |
| `scraper.py` | Playwright/Firefox: выдача по страницам, фото, страница объявления, куки Zen, города, кэш |
| `market.py` | отсев аксессуаров, статистика рынка, скидка, балл и вердикт лота |
| `analyzer.py` | запросы к LM Studio, правила-«красные флаги» на случай, когда ИИ недоступен |
| `models.py` | Pydantic-модели запроса и ответа |
| `config.py` | настройки и пути |
| `templates/index.html`, `static/app.js` | интерфейс |
| `test_*.py` | старые отладочные скрипты (обход блокировок, селекторы). К работе приложения не относятся, запускаются вручную |

## API

| Метод | Адрес | Что делает |
|---|---|---|
| `POST` | `/api/analyze` | запускает анализ, возвращает `job_id` (параметры — модель `FilterParams` в `models.py`) |
| `GET` | `/api/jobs/{job_id}` | состояние (`running` / `done` / `error` / `cancelled`), этап, процент и готовый результат |
| `POST` | `/api/jobs/{job_id}/cancel` | отменяет анализ |
| `GET` | `/api/health` | жив ли сайт и отвечает ли LM Studio |

Анализы выполняются строго по одному: Авито не любит параллельные запросы.

## Приватность

- Куки Авито читаются из профиля Zen **только локально** и нужны браузеру Playwright; никуда не отправляются, кроме самого avito.ru.
- В репозиторий не должны попадать профили браузеров, история и дампы страниц — всё это перечислено в `.gitignore`.
  Перед коммитом полезно проверить `git add -n .`.
- Нейросеть работает локально в LM Studio, тексты объявлений в облако не уходят.

## Что проверено, а что нет

- ✅ Извлечение карточек (цена, фото, описание, локация) — на сохранённых страницах Авито.
- ✅ Весь конвейер, интерфейс, отмена, ошибки — на тестовых данных с реальной моделью в LM Studio.
- ✅ Запуск через `start.bat` при уже работающем LM Studio.
- ⚠️ Не проверено на живом Авито: страницы выдачи со второй и дальше, селекторы страницы объявления
  (цена, описание, «снято с публикации»), фильтр доставки, транслитерация редких городов.
  Если сверка цен у всех лотов пишет «не сверена» — вероятнее всего, поменялась вёрстка и надо поправить
  `ITEM_PAGE_JS` в `scraper.py`.
- ⚠️ Запуск LM Studio самим `start.bat` (когда он не открыт) не тестировался.

## Ограничения

- Цены сравниваются с общей медианой по запросу. Разные версии товара (например PS5 Fat и Slim) в одной выдаче смешиваются —
  уточняйте запрос («PS5 Slim 1TB»).
- Локальная 7B-модель разбирает лот ~10 секунд, поэтому ИИ смотрит только топ.
