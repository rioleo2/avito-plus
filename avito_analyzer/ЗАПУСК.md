# Как запустить

1. Дважды кликните **`start.bat`** в этой папке.
2. Подождите: откроется LM Studio (если ещё не запущен), затем в браузере откроется сайт `http://127.0.0.1:8000`.
3. Введите запрос, например `PS5`, нажмите **Найти**. Анализ занимает 1–3 минуты.

Остановить: закройте чёрное окно консоли.

**Если что-то не так**
- LM Studio не поднял сервер сам → в LM Studio откройте **Developer → Start Server** и загрузите модель. Без него сайт работает, но без оценки ИИ.
- «Доступ ограничен» / 429 от Авито → подождите 15–30 минут и повторите.
- При самом первом запуске могут доустановиться пакеты и Firefox — это нормально, один раз.
